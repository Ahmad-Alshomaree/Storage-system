# Storage System

A desktop application for managing storage, clients, products, and shipping records. Built with Tauri, React, Next.js, and SQLite.

## Download and Installation

The application is distributed as native installers generated by Tauri. Pre‑built packages for each platform are published on the GitHub releases page. You can also build the packages yourself if you prefer.

### Obtaining a Release

1. Go to the [Releases](https://github.com/Ahmad-Alshomaree/Storage-system/releases) page of this repository.
2. Download the appropriate file for your OS:
   - **Windows**: `storagesystem_<version>_x64-setup.exe` (installer) or portable `.zip` if provided.
   - **Linux**: `storagesystem_<version>_amd64.AppImage` (recommended), `.deb`, or `.rpm` packages.
   - **macOS**: `.dmg` or `.pkg` file when available.

(Replace `<version>` with the actual release tag number.)

### Linux Installation

#### Using AppImage (Recommended - No installation required)
```bash
chmod +x storagesystem_<version>_amd64.AppImage
./storagesystem_<version>_amd64.AppImage
```

#### Using DEB Package (Ubuntu/Debian)
```bash
sudo dpkg -i storagesystem_<version>_amd64.deb
# If you get dependency errors, run:
sudo apt-get install -f
```

#### Using RPM Package (Fedora/RHEL)
```bash
sudo rpm -i storagesystem-<version>-1.x86_64.rpm
```

### Windows Installation

### Windows Installation

#### Using EXE Installer (Recommended)
1. Download `storagesystem_<version>_x64-setup.exe` from the [Releases](https://github.com/Ahmad-Alshomaree/Storage-system/releases) page
2. Double-click the `.exe` and follow the installer steps
3. Launch the application from the Start menu, desktop shortcut, or pinned taskbar

#### Portable Version (Alternative)
If you prefer a portable release that does not require installation:
1. Download the `.zip` archive from the release assets

## Building & Packaging Your Own Copy

If you'd like to generate the installers yourself (for development, custom branding, or a new release), follow these steps:

### Prerequisites
- Node.js LTS
- pnpm package manager
- Rust toolchain (stable) with `cargo`

### Build commands
```bash
# install dependencies
pnpm install

# run migrations / seed database if necessary
pnpm db:migrate

# start development mode (web + Tauri)
pnpm tauri dev

# create production packages:
pnpm tauri build
```

The `tauri build` command will produce platform-specific binaries under `src-tauri/target/release/bundle/`. Copy those files into a new GitHub release to make them downloadable.

### Publishing a Release
1. Tag the commit: `git tag v1.2.3 && git push origin v1.2.3`
2. On GitHub, create a new release using the same tag.
3. Upload the files from the `bundle` directory (AppImage, .exe, .dmg, etc.).

GitHub will then host the installers, and users can download them directly from the Releases page.

## Features

- **Client Management**: Add, edit, and manage client information
- **Product Management**: Track products, pricing, inventory, and shipping details
- **Shipping Management**: Handle shipping records and logistics
- **Debit Tracking**: Monitor financial transactions and debits
- **Data Import/Export**: Support for Excel file uploads and data management
- **Multi-language Support**: Built-in internationalization

## Development

### Prerequisites

- Node.js (LTS version)
- pnpm
- Rust

### Setup

1. Clone the repository:
```bash
git clone https://github.com/Ahmad-Alshomaree/Storage-system.git
cd Storage-system
```

2. Install dependencies:
```bash
pnpm install
```

3. Set up the database:
```bash
pnpm db:migrate
```

4. Run in development mode:
```bash
pnpm tauri dev
```

5. Build for production:
```bash
pnpm tauri build
```
